Heritage map preview

Every marker is a record in the content database with coordinates. The map asks for what's in view; toggling a layer is a filter on the same records. Fictional site, not a client product.

Rendered with MapLibre GL (the open-source fork of Mapbox GL, same API) so this page needs no access token. In production the same code runs on Mapbox GL with Mapbox styles and the Directions API for routes. Base map © OpenStreetMap contributors, tiles by OpenFreeMap.
